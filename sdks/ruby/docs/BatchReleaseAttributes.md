# UnitFinanceSdk::BatchReleaseAttributes

## Properties

| Name | Type | Description | Notes |
| ---- | ---- | ----------- | ----- |
| **amount** | **Integer** | The amount (in cents) to move from the batch account to the receiver account. |  |
| **description** | **String** | Description of the payment. |  |
| **sender_name** | **String** | Name of the sender, before combining the payments. |  |
| **sender_address** | [**AddressType**](AddressType.md) | Address of the sender. |  |
| **sender_account_number** | **String** | Unique identifier to monitor for similar sending accounts, could be the BIN + last four digits of the card number OR a unique identifier generated by you for the sender. |  |

require 'unit_finance_sdk'

instance = UnitFinanceSdk::BatchReleaseAttributes.new(
